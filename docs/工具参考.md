# 工具参考

本文列出服务对外暴露的全部工具与 resource 的输入输出契约。标注"需要工作区"的能力仅在设置 `GEO_WORKSPACE_ROOT` 后注册。

所有工具均为显式注册,输入经 Pydantic 严格校验;成功结果提供结构化输出与 output schema,错误通过 MCP 工具错误语义返回并携带错误代码。

## 通用约定

- **数据引用**:一律使用管理员登记的 `dataset_id`,不接受服务器路径或 URL。
- **来源引用 `SourceRef`**:分析工具的输入来源,二选一:
  - `{"dataset_id": "<id>", "layer": "<可选图层>"}`,或
  - `{"artifact_id": "<id>", "layer": "<可选图层>"}`(复用先前成果)。
- **任务结果 `TaskResult`**:`task_id`、`artifacts`(成果元数据列表)、`summary`(统计摘要)、`warnings`。
- **成果元数据 `ArtifactInfo`**:`artifact_id`、`task_id`、`kind`(vector/image)、`format`(gpkg/png)、`mime_type`、`uri`、`size_bytes`、`sha256`。
- **错误代码**:`DATASET_NOT_FOUND`、`DATASET_TYPE_MISMATCH`、`INPUT_TOO_LARGE`、`PATH_NOT_ALLOWED`、`LAYER_REQUIRED`、`INVALID_VECTOR_DATA`、`INVALID_RASTER_DATA` 等。

## 元数据工具(始终可用)

### `geo_vector_info`

检查已注册矢量数据的图层、CRS、字段、几何类型、要素数量与原始坐标边界。

输入:

```json
{"dataset_id": "roads_demo", "layer": null}
```

- `layer` 可选;多图层数据必须显式指定,不会静默选择第一层。
- 支持 GeoJSON(`.geojson`/`.json`)、GeoPackage(`.gpkg`)、Shapefile(`.shp`)。
- 只读元数据:流式遍历要素,不计算面积或字段统计。

输出:驱动、图层名称、可用图层、要素数量、几何类型、CRS、坐标单位、边界(`xmin,ymin,xmax,ymax`,源 CRS 坐标;空数据为 `null`)、字段类型、空几何数量与警告。`null_geometries` 仅指缺失几何。

### `geo_raster_info`

检查已注册 GeoTIFF 的尺寸、波段、CRS、边界、仿射变换、像元大小、NoData、波段描述与单位。

输入:

```json
{"dataset_id": "dem_demo"}
```

- 支持 GeoTIFF(`.tif`/`.tiff`);只读文件内元数据,不扫描像元统计、不加载外置辅助元数据或概览。
- `pixel_size` 为列/行像元向量长度(源 CRS 单位),支持旋转栅格。
- 投影坐标系按 CRS 真实单位换算为米;地理坐标系的 `pixel_size_meters` 为 `null`,不做粗略经纬度换算。
- CRS 缺失返回 `null`、`crs_type="undefined"` 与警告,不猜测。
- 非有限 NoData 以 `"NaN"`、`"+Infinity"`、`"-Infinity"` 字符串表示,保证 JSON 可序列化。
- 不返回全图最值、均值或 NoData 百分比。

## 数据集与任务工具(需要工作区)

### `geo_list_datasets`

列出已登记数据集的 ID 与类型(vector/raster),不暴露服务器路径。无输入参数。

### `geo_get_task_info`

读取已持久化任务的状态、输入哈希、参数、警告与输出元数据。

输入:`{"task_id": "<id>"}`。任务为同步执行;进程中断可能遗留 running 状态。ID 不提供多用户授权(单操作员服务)。

### `geo_get_artifact_info`

读取已校验的成果元数据。输入:`{"artifact_id": "<id>"}`。实际文件字节通过 `resources/read` 读取其 `uri` 获取。

## 分析工具(需要工作区)

### `geo_vector_buffer`

在投影分析 CRS 中创建平面缓冲区,保留属性,输出 GPKG。

输入:

```json
{"source": {"dataset_id": "roads_demo"}, "distance_meters": 500, "analysis_crs": "EPSG:32650"}
```

- `distance_meters` 取值 (0, 1000000];为投影面距离,非测地距离。
- 地理坐标源必须显式提供投影 `analysis_crs`(形如 `EPSG:xxxxx`);坐标真实变换并校验是否落在 CRS 适用范围内。
- 不做隐式几何修复;输出 CRS 为分析 CRS;创建新的隔离任务。

### `geo_vector_clip`

用多边形掩膜的并集裁剪源要素,保留源属性,输出 GPKG。

输入:

```json
{"source": {"dataset_id": "roads_demo"}, "mask": {"dataset_id": "mask_demo"}}
```

- 双方 CRS 必须存在且一致;不做隐式重投影或 CRS 重标。
- 保留仅边界相交与混合维度相交;空结果是合法的空 GPKG 图层。

### `geo_spatial_join`

一对多平面空间连接,保留左几何,输出 GPKG。

输入:

```json
{"left": {"dataset_id": "points_demo"}, "right": {"dataset_id": "zones_demo"}, "predicate": "intersects", "how": "left"}
```

- `predicate`:`intersects` / `within` / `contains`(按"左几何 predicate 右几何"求值),默认 `intersects`。
- `how`:`left` / `inner`,默认 `left`;未匹配的左行右属性为 `null`。
- 输出属性加 `left_`/`right_` 前缀,并含 `__left_row`/`__right_row`(零基源序)。
- 不支持 nearest、right join 或聚合;要求 CRS 一致。

### `geo_render_vector_map`

渲染带图例、源 CRS 与坐标边界的 PNG 矢量地图。

输入:

```json
{"source": {"dataset_id": "roads_demo"}, "value_field": null, "title": "Vector map", "width": 1000, "height": 700}
```

- `value_field` 可选数值字段,使用顺序色带;null/非数值会被拒绝。
- `title` 仅 ASCII(内置字体),最长 120 字符;`width`∈[480,2000],`height`∈[360,2000]。
- 不请求底图或网络;保留多边形孔洞。
- 图像以真实 PNG 字节通过 `resources/read` 交付,而非服务器文件路径。

## Resource

### `artifact://{artifact_id}`

读取已完成成果(GPKG 或 PNG)的有界、校验和验证的二进制内容,`mime_type` 为 `application/geopackage+sqlite3` 或 `image/png`。用于下载分析产物。
